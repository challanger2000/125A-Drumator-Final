# Drumator 1.5 – eight audition kits (NOT RELEASED)

This folder contains 8 × 8 = 64 unchanged audio one-shots staged ONLY on `develop/v1.5.0`,
using the fixed Beat Creator row order: **01 BD, 02 Snare, 03 CHH, 04 OHH,
05 Low Tom, 06 High Tom, 07 Crash, 08 Clap**.

**These are quality candidates, NOT approved factory kits and NOT shipped with the retail VST3.**
The audio has been gathered from existing publicly attributed repositories, but
no human listening approval or subjective audio comparison is recorded. The
`sources.tsv` file maps ALL 64 WAVs to their exact upstream path and identical
Git blob checksum, avoiding vague claims about their origins.

## Musical source decisions and limitations

| Kit folder | Style | Audio source / relevant licensing | Important limitation |
| --- | --- | --- | --- |
| Industrial_NDH | INDUSTRIAL / NDH | Karoryfer live drums + Fugue State Audio electronic accent (Stargate pack, CC0) | Acoustic/electronic hybrid, requires careful gain matching |
| EBM_LinnDrum | EBM | Oramics LM-2 LinnDrum sampling, catalog labels Public Domain | Original sampling provenance should be retained |
| Techno_909_Style | TECHNO | Octal Samples, CC0, original DSP synthesis | **909-style approximation; NOT a sampled Roland TR-909**; replacement candidate required |
| House_TR505 | HOUSE | Oramics TR-505, catalog labels Public Domain | TR-505, **not** a TR-707, so not final requested historical house reference |
| Studio_Rock_Pearl | ROCK | Oramics Pearl Master Studio, credited to enoe under CC BY 3.0, plus Stargate CC0 clap | Single-hit reduced representation of an acoustic kit |
| Metal_Raw_Acoustic | METAL | Karoryfer live drums + Fugue State Audio (Stargate, CC0) | Not a fully produced modern triggered Metal kit yet |
| HipHop_SDB | HIP-HOP | Fugue State Audio SDB synth kit, public domain through Stargate | **Synthetic kit, not an authentic SP-1200 / acoustic break sample**; replacement candidate required |
| DrumNBass_Gogodze | DRUM & BASS | Gogodze Phu Vol II CC0 (Karoryfer) + Stargate CC0 accents | Real recorded core; some electronic extras, needs listening test |

## Build/load audition kits

The separate CI workflow `kit-audition-pack.yml` runs the project's own
`drumator_kit_pack` on each eight-WAV folder and uploads eight `.125akit`
files as a GitHub Actions artifact. These embed the audio and can be copied into
`125A Drumator.vst3/Contents/Resources/Samples/` for a **development** installation.
Using the KITS browser loads the sound set without changing patterns or Song.
Do **not** copy these candidates into a customer release unreviewed.
